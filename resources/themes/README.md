# Theme asset studies

This folder holds design phase worksheets and inventories for Oxygen's built-in
themes. A theme folder groups its approved reference sheets and a filled copy of
the common asset checklist. These are design resources; they are not Android
runtime assets or implementation approval.

## Folders

- [`smoked-quartz/`](smoked-quartz/) — a Glass theme art direction study using
  Compose-native background techniques.
- [`THEME_ASSET_TEMPLATE.md`](THEME_ASSET_TEMPLATE.md) — duplicate this for
  each theme and fill in every section. Mark inapplicable asset types `None`
  with a reason so every theme is reviewed against the same complete inventory.

The product pages remain **Now → Hourly → Daily → Details**. A theme may give
each page a distinct visual recipe while preserving its information, navigation,
weather meaning, provenance, and accessibility semantics.
