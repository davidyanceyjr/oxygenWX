# Production theme design references

These project-local boards, screen crops, detail crops, backdrops, and SVG examples are design references for the built-in production theme family. They are not runtime Android resources and do not set pixel-exact acceptance requirements.

- `one-app-many-personalities/` — overview board and theme phone crops.
- `atmospheric/`, `glass/`, `minimal-oled/`, `instrument/`, `terminal/` — theme-specific backdrops and available concept material.
- `shared/` — package/component boards, shared examples, and reference SVGs.

The written product and accessibility contracts take precedence where an image conflicts with data meaning, chronology, provenance, missing-data behavior, page navigation, or accessibility. Large boards must not be placed in `app/src/main/res/`.
